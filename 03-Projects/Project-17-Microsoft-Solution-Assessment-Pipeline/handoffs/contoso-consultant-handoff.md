# Technical Consultant Handoff
## Contoso Manufacturing

### Opportunity Summary

**Customer:** Contoso Manufacturing  
**Microsoft AE:** Alex Rivera  
**Solution Area:** Azure Infrastructure  
**Recommended Assessment:** Infrastructure Assessment  
**Priority:** High  
**Current Stage:** Qualified / Consultant Handoff  

## Business Objective

Contoso Manufacturing is evaluating Microsoft Azure for modernizing portions of its existing on-premises infrastructure.

The customer wants to understand whether Azure can improve scalability, security, operational efficiency, and infrastructure management.

## Current Environment

- Approximately 500 employees
- 50 on-premises Windows servers
- Multiple business workloads hosted locally
- Azure migration under consideration
- Workload dependencies require further discovery

## Customer Concerns

- Migration cost
- Security
- Business downtime
- Workload dependencies
- Migration planning

## Assessment Goals

The assessment should help:

- Understand the existing server environment
- Identify workload dependencies
- Evaluate workload suitability for Azure
- Identify migration risks
- Support cost and sizing discussions
- Identify security considerations
- Prioritize potential migration candidates

## Known Blockers

- Migration budget has not been finalized
- Acceptable downtime has not been defined
- Application dependencies require additional discovery
- Security requirements require clarification

## Information Required Before Kickoff

- Server inventory
- Critical application list
- Workload dependencies
- Current infrastructure architecture
- Security requirements
- Compliance requirements
- Migration timeline
- Business priorities
- Primary technical contacts

## Next Actions

1. Confirm customer stakeholders.
2. Complete remaining discovery.
3. Confirm assessment scope.
4. Assign Technical Consultant.
5. Provide qualification information to the consultant.
6. Resolve scheduling blockers.
7. Schedule assessment kickoff.

## Expected Outcome

A successful handoff provides the Technical Consultant with sufficient business and technical context to begin the assessment while ensuring Microsoft, the customer, and Inviso are aligned before kickoff.
