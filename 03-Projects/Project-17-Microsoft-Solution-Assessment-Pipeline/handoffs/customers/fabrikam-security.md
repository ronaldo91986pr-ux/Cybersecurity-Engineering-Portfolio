# Fabrikam Financial — Security Assessment Opportunity

> Fictional customer scenario created for portfolio and training purposes.

## Opportunity Overview

**Customer:** Fabrikam Financial  
**Microsoft AE:** Sarah Mitchell  
**Solution Area:** Microsoft Security  
**Assessment:** Security Assessment  
**Current Stage:** Qualification  
**Priority:** High

## Business Situation

Fabrikam Financial has approximately 800 employees using a combination of Microsoft 365, Windows devices, and cloud services.

The organization wants to strengthen its security posture following an increase in suspicious login attempts and concerns about account compromise.

## Customer Concerns

- Suspicious authentication attempts
- Inconsistent MFA adoption
- Excessive user permissions
- Limited visibility into security events
- Protection of cloud identities
- Endpoint security

## Discovery Questions

### Identity

1. How are users currently authenticated?
2. Is Multi-Factor Authentication enforced for all users?
3. How are privileged or administrator accounts protected?
4. How are user accounts created, modified, and disabled?

### Access

5. How are permissions and administrative roles assigned?
6. Is least privilege currently being followed?
7. Are access policies reviewed regularly?

### Devices

8. How are corporate devices managed and protected?
9. What endpoint security technologies are currently deployed?

### Monitoring

10. How are suspicious login attempts currently investigated?
11. What security alerts and logs are being monitored?
12. Who is responsible for responding to security incidents?

## Initial Assessment Recommendation

Based on the initial information, a Microsoft Security-focused assessment appears appropriate.

The assessment should help identify gaps across identity, access, endpoint protection, and cloud security while providing information that can support future security improvements.

Final scope should be confirmed with the customer, Microsoft stakeholders, and the assigned Inviso Technical Consultant.
