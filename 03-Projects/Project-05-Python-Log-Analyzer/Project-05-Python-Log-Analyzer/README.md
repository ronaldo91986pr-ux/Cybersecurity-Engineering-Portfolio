# 🔐 Python Security Log Analyzer

## 📌 Overview

The Python Security Log Analyzer is a cybersecurity automation project that analyzes Linux SSH authentication logs to identify suspicious login activity.

The application automatically detects failed login attempts, counts successful logins, identifies attacker IP addresses, detects possible brute-force attacks, and generates a security incident report.

---

# 🚀 Features

- Reads Linux SSH authentication logs
- Detects failed login attempts
- Counts successful logins
- Identifies unique attacker IP addresses
- Detects possible brute-force attacks
- Generates an incident report
- Automates security log analysis
